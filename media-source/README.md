(e.g. `cwebp -q 86 -m 6 robot-hero.png -o ../public/media/robot-hero.webp`).

- `robot-hero.png` → `public/media/robot-hero.webp` (hero, three-quarter CAD render)
- `robot-poster.jpg` → `public/media/robot-poster.webp` (robot section, low-angle CAD render)
